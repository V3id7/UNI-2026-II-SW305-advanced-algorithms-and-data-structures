# Advanced Algorithms and Data Structures — SW305

**Official course name:** Algoritmia y Estructura de Datos Avanzada.

Code developed during the Advanced Algorithms and Data Structures classes in the 2026-II semester at Universidad Nacional de Ingeniería (UNI), Peru.

## Academic Information

- Faculty: Faculty of Industrial and Systems Engineering.
- Degree programme: Software Engineering (I3).
- Course: Advanced Algorithms and Data Structures (SW305).
- Semester: 2026-II.

## Purpose

To preserve and organise the examples and implementations developed in class for study and reference.

The code reproduces the professor's examples, preserving their syntax and logic. Comments and console messages have been adapted into English.

C++ is used as a tool to implement the concepts covered in the course.

## Current Contents

| Folder             | Contents                                       |
| ------------------ | ---------------------------------------------- |
| `01_BuildingBlocks` | Basic functions and utilities.                 |
| `02_Arrays`        | Examples using `std::array`.                    |
| `03_Vectors`       | Examples using `std::vector`.                   |
| `04_Deques`        | Examples using `std::deque`.                    |
| `05_Lists`         | Examples using `std::list`.                     |
| `06_Sets`          | Examples using `std::set` and `std::multiset`.   |
| `07_Maps`          | Examples using `std::map`.                      |

The repository will be updated as the course progresses.

## Development Environment

- Language: C++.
- IDE: CLion.
